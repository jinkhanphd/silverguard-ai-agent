# Safety & Limitations

- 본 프로젝트는 경진대회/교육용 MVP입니다.
- 의료기기, 의료진단 또는 응급의료 판단 시스템이 아닙니다.
- 위험점수와 임계값은 임상적으로 검증된 수치가 아닌 MVP 시연용 휴리스틱입니다.
- 현재 데이터는 직접 입력/시뮬레이션/Recorded Data 형태이며 실제 웨어러블·센서와 연결되어 있지 않습니다.
- Browser Notification API는 로컬 브라우저/OS 알림이며 원격 보호자 SMS/FCM 전송을 의미하지 않습니다.
- 사건 상태는 LocalStorage에 저장되므로 다중 사용자, 서버 동기화, 인증, 암호화, 고가용성을 제공하지 않습니다.
- 실제 현장 적용 전 개인정보 보호, 사용자 인증, 기관 연계, 실데이터 검증, 응급 대응정책 검토가 필요합니다.
- 실제 응급상황에서는 119, 보호자, 복지기관 및 의료전문가의 판단이 우선입니다.
