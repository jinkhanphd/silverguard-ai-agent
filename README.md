# SilverGuard
독거노인 실시간 위기알림 AI Agent

## 핵심 Workflow
상태 입력
→ 데이터 검증
→ 이상징후 분석
→ 위험도 판단
→ Tool 실행
→ Memory 저장
→ 보호자 확인
→ Feedback

## 실행 방법
GitHub Pages 또는 Chrome / Edge에서 실행

## AI Agent 구성
- Goal: 독거노인 위험 조기 감지
- Reasoning: 통계적 기준선 + 복합 위험규칙
- Tool: Browser Notification API
- Memory: LocalStorage
- Feedback: 보호자 확인 / 재알림
- Test: 6개 대표 Test Case

## 주의
본 프로그램은 경진대회용 MVP이며 의료진단 프로그램이 아닙니다.
